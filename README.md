# Flight Price Predition
It is a machine learning project which predict flight price based on past data

# Tech stack
- **Language**: Python
- **Libraries**: Numpy, Pandas, Matplotlib, Scikit-learn

# Quick start

## Prerequities
- Vs code
- Install all python libraries in your system/virtual environment

## Installations
1. Clone the repository
```
git clone https://github.com/jitendra-rathore-iitm/Flight-Price-Predictor---ML.git

```
2. Install Dependencies
```
cd Flight-Price-Predictor---ML
pip install reuirements.txt
```
